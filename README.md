# Movie Ticket Booking System

A menu-driven C++ console application for a single cinema.

## Features
- List movies and shows
- View AVAILABLE / BOOKED seats
- Book multiple seats
- SILVER ₹150, GOLD ₹250, PLATINUM ₹400 pricing
- UPI, Card and Cash payment
- Failed payment releases seats
- Ticket generation with unique booking ID
- Booking cancellation releases seats

## Compile and Run
```bash
g++ main.cpp -o movie_booking
./movie_booking
```

> This project intentionally follows the assignment rule of **no header files**. Each class is placed in a separate `.cpp` file and included where needed.

## OOP Concepts
Encapsulation, Abstraction, Inheritance, Runtime Polymorphism, Compile-Time Polymorphism, Static Members, Composition, Aggregation and Association.
